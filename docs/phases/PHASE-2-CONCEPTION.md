# Phase 2 : Conception UX/UI

## Objectif
Concevoir l'interface utilisateur et l'expérience utilisateur de l'application.

## Charte Graphique

### Couleurs
```css
:root {
  --color-primary: #0D8F8F;      /* Turquoise Bag'up */
  --color-secondary: #F7E300;    /* Jaune Bag'up */
  --color-accent: #F04A3A;       /* Rouge Bag'up */
  --color-background: #FFFFFF;
  --color-text: #1A1A1A;
  --color-text-light: #6B7280;
  --color-success: #10B981;
  --color-warning: #F59E0B;
  --color-error: #EF4444;
}
```

### Typographie
- **Titres** : Syne (Bold, Semi-Bold)
- **Corps** : DM Sans (Regular, Medium)

### Style
- Moderne et épuré
- Coins arrondis (8-16px)
- Ombres légères
- Animations fluides
- Références : Uber, Glovo, Yango
