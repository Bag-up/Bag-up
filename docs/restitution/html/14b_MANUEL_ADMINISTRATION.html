1. Accès admin

  1. Ouvrir https://admin.bagup.app
  2. Se connecter avec un compte Administrateur / Staff
  3. Ne jamais partager le mot de passe admin en clair hors canal sécurisé

Les comptes admin sont gérés en base (rôle admin/staff).

2. Missions principales de l’admin

ModuleActions
UtilisateursVoir clients / prestataires / commerçants, bloquer, vérifier KYC
PrestatairesValider pièces, adhésion payée, rejeter KYC, motif de rejet
AbonnementsSuivre paiements d’adhésion, impayés, remboursements à traiter
PaiementsMissions / courses (Bictorys), statuts (succès, abandonné…)
Missions / CoursesSuperviser litiges, statuts, suivis
ContenuBannières, promos, message de mise à jour app (APP_LATEST_VERSION)
MarketplaceBoutiques, commandes, modération selon activation

3. Validation prestataire (KYC)

Parcours type :

  1. Inscription + OTP
  2. Paiement adhésion
  3. Admin vérifie documents
  4. Validation → accès app
  5. En cas de rejet : motif visible côté app + éventuel remboursement à marquer

Anti-Gaspi peut suivre un parcours « vérification seule » selon configuration.
