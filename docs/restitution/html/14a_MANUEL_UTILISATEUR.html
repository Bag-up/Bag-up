Manuel utilisateur — Application Bag’up

Version app : 1.0.23
Public : Clients, Prestataires, Commerçants
Compte de référence projet : lanternelabel@gmail.com

1. Présentation

Bag’up met en relation des clients avec des prestataires pour :

  • Collecte et livraison
  • Courses (moto / voiture)
  • Démarches administratives
  • Marketplace / Anti-Gaspi (selon activation)

Téléchargement

  • Android : Google Play (sn.bagup.app)
  • iOS : App Store / TestFlight

2. Création de compte

  1. Ouvrir Bag’up
  2. Choisir le pays / indicatif
  3. Saisir le numéro de téléphone
  4. Valider le code OTP SMS
  5. Choisir l’espace :
    • Client
    • Prestataire (livraison / courses / démarches)
    • Commerçant (boutique / Anti-Gaspi)

Un même numéro peut ouvrir plusieurs espaces.

Prestataire — inscription

  • Photo de profil obligatoire
  • Type : Courses & livraisons ou Démarches
  • Véhicule : Moto / Voiture / Vélo (si applicable)
  • Pièces d’identité
  • Paiement d’adhésion puis validation admin

Client

  • Profil simple, puis accès immédiat aux services

3. Espace Client

3.1 Demande de collecte / livraison / démarches

  1. Accueil → créer une demande
  2. Renseigner retrait + livraison (ou lieux liés aux démarches)
  3. Choisir urgence / détails
  4. Voir le prix estimatif
  5. Commander et payer selon le parcours affiché

3.2 Course (personnes)

  1. Accueil → Course
  2. Départ (géolocalisation possible)
  3. Destination (saisie + suggestions de lieux)
  4. Choisir Moto ou Voiture
  5. Voir le prix → Commander
  6. Suivre le chauffeur sur la carte

Astuce : coller des coordonnées GPS / lien Maps peut remplir automatiquement la destination.

3.3 Suivi & notation

  • Statuts de mission / course visibles dans l’historique
  • Après livraison : noter le prestataire

3.4 Paiement

Modes disponibles selon configuration : Wave, Orange Money, Free Money, carte (passerelle Bictorys / Stripe).

4. Espace Prestataire

  1. Se connecter sur l’espace Prestataire
  2. Être payé + vérifié pour recevoir des missions
  3. Accepter / refuser les demandes
  4. Mettre à jour le statut (en route, arrivé, terminé)
  5. Consulter gains et abonnement

Démarches uniquement : inscription sans véhicule, catalogue de procédures côté client.

5. Espace Commerçant / Anti-Gaspi

  1. Créer / gérer la boutique
  2. Publier des offres
  3. Suivre les commandes
  4. Respecter l’abonnement / validation admin si demandé

6. Notifications & compte

  • Notifications push selon paramètres téléphone
  • Profil : photo, infos, documents
  • Support : contacter l’équipe via les canaux communiqués par Bag’up

7. Mise à jour de l’application

Si une mise à jour est proposée :

  1. Ouvrir le popup Mise à jour disponible
  2. Installer maintenant (OTA) ou ouvrir le store
  3. Rouvrir l’app après installation
